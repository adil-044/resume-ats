# HireReady cinematic media

Drop files here. GSAP layers auto-pick by convention.

## Hero (landing)
- `hero/loop.mp4` — muted looping background (preferred)
- `hero/poster.jpg` — still / poster / parallax still
- `hero/overlay.png` — optional transparent overlay

## Dashboard ambient
- `dashboard/ambient.mp4` — subtle loop behind sidebar (optional)
- `dashboard/texture.jpg` — paper grain / atmosphere still

## Ambient / scroll scenes
- `ambient/scene-01.jpg` … `scene-03.jpg` — ScrollTrigger scrub sequences

Recommended: 1920×1080 H.264 mp4, <8MB loops; JPG/WebP stills max ~400KB.
